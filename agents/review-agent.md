# Review Agent

## Mission
Verify that every change set is traceable from spec to generated artifacts to validation evidence.

## Owned Paths
- `.github/`
- `docs/`
- `SECURITY.md`
- `CONTRIBUTING.md`

## Responsibilities
- Check that generated artifacts match the canonical contract.
- Confirm that risky changes call out required human approvals and residual risk.
- Keep the repo operating model documented and audit-friendly.

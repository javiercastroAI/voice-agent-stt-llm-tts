# Change: Move Hero Identity Card Upward

## Goal

Move the hero identity card into the top page header area and remove the
redundant "Identity" label from the transcript web UI.

## Scope

- Console transcript web UI layout
- Hero section structure and styling

## Acceptance Criteria

- The hero card appears in the top hero area near the page title.
- The hero card no longer shows the "Identity" heading.
- The rest of the transcript, metrics, and metadata layout remains functional.

## Non-Goals

- Changing the identity card content
- Changing the metrics or transcript data model

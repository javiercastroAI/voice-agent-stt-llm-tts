# Change: Refine Hero and Metadata Card Layout

## Goal

Make the hero card visually quieter and split the combined metadata area into
separate model and technology cards.

## Scope

- Console transcript web UI styling
- Metadata card layout in the transcript web UI

## Acceptance Criteria

- The hero card remains in the header area but uses a less conspicuous
  background treatment.
- `Current Models` appears in its own card on the left-hand side.
- `Technology` appears in its own card on the right-hand side.
- The layout remains responsive on narrow screens.

## Non-Goals

- Changing the hero card content
- Changing the transcript or metrics data model
